# 시사경제용어사전 — 웹 파일럿

엑셀 원본(3,029개 용어)을 그대로 쓰는 사전 + 4지선다 퀴즈 + 오답 복습 앱

https://dup04205.github.io/economic-dictionary-app/

## 파일 구조

```
econ-dict/
├─ econ-dict.vbs       윈도우 런처 (콘솔 창 없이 index.html 을 연다)
├─ econ-dict-fallback.bat  VBScript 가 막힌 환경용 대체 런처
├─ index.html          화면 뼈대 (앱바 / 4개 탭 / 상세 시트)
├─ css/style.css       라이트·다크 테마, 모바일 우선 레이아웃
├─ js/
│  ├─ storage.js       localStorage 읽기·쓰기 계층 (오답·즐겨찾기·통계·테마)
│  ├─ dictionary.js    데이터 적재, 초성/알파벳 색인, 검색, 목록 렌더, 상세 시트
│  ├─ quiz.js          4지선다 출제 엔진, 정답 마스킹, 채점, 결과
│  └─ app.js           탭 라우팅, 오답노트 화면, 통계 화면, 부트스트랩
└─ data/
   ├─ terms.js         앱이 읽는 데이터셋 (window.TERMS)
   └─ terms.json       같은 데이터의 JSON 원본 (안드로이드 이식용)
```

## 데이터 스키마

```json
{ "id": 1, "topic": "사회", "term": "0.5인 가구", "initial": "0-9", "def": "…" }
```

- `topic` — 금융 815 / 경제 705 / 경영 631 / 공공 556 / 과학 210 / 사회 112
- `initial` — 정렬·색인 키. 한글은 초성(된소리는 예사소리로 통합), 영문은 대문자, 숫자는 `0-9`

## 기능

**사전** — 용어·설명 전문 검색(하이라이트), 주제 필터, 가나다·ABC순 / 주제별 / 즐겨찾기
정렬, 초성·알파벳 색인, 60개 단위 무한 스크롤, 상세 시트에서 즐겨찾기 지정.

**퀴즈** — 범위(전체·주제·즐겨찾기·오답노트) × 유형(설명→용어 / 용어→설명 / 혼합) ×
문항 수(5·10·20·30). 오답 보기는 같은 주제에서 뽑아 난도를 유지한다. 설명 안에 정답
용어가 나오면 `○○○`로 가린다(괄호 병기 형태까지 처리, 미탐지율 약 1%). 키보드 1~4 선택,
Enter로 다음 문항.

**오답노트** 
— 틀린 용어를 오답 횟수·마지막 시각과 함께 저장 
- 복습 퀴즈에서 연속 2회 맞히면 목록에서 빠짐
- 다시 틀리면 연속 기록은 0으로 돌아감

**통계** 
— 누적 문항·정답률·연속 학습일·주제별 정답률. 학습기록 JSON 내보내기와 초기화.

## 저장 위치
